# Assignment 4: Geospatial Alerts and Monitoring

## Overview

This project contains interactive Leaflet web maps using data from:

- OpenStreetMap
- National Weather Service (NWS)
- Iowa State Mesonet
- United States Geological Survey (USGS)

## Homepage
- Clean homepage with interactive tab features to select the map of interest
## Weather Map

Features:
- Live weather alerts
- Weather radar imagery
- Severity-based alert styling
- Interactive popups

## Earthquake Map

Features:
- Recent earthquake activity
- Magnitude-based symbol sizes
- Magnitude-based color styling
- Interactive popups
- Earthquake legend

## Combined Map (Bonus)

Features:
- Weather alerts and earthquake data
- Layer toggle control
- Integrated geospatial monitoring interface
